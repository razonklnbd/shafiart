# Contributing to Shafiart

First off, thank you for your interest in contributing to **Shafiart**! As an open-source project licensed under the GPLv3, community contributions help keep this tool robust, privacy-focused, and useful for everyone.

Please follow these guidelines to make your contribution experience smooth:

## Code of Conduct
By participating, you are expected to maintain a welcoming, respectful, and constructive tone in issues, pull requests, and discussions.

## How to Report Bugs & Request Features
1. Check the **Issues** tab to ensure the bug or feature hasn't already been reported.
2. Open a new issue with a clear description, reproduction steps (for bugs), or clear use cases (for features).

## Submitting Pull Requests
1. **Fork** the repository and create your feature branch from `main` (e.g., `git checkout -b feature/amazing-tool`).
2. **Commit** your changes with clear, descriptive commit messages.
3. **Test** your changes locally by reloading the extension in Chrome (`chrome://extensions/`).
4. **Push** to your fork and submit a **Pull Request** targeting the `main` branch.

All contributions must comply with the terms of the project's GPLv3 license.
