# Shafiart

**Shafiart** is a fast, lightweight, and privacy-friendly Chrome extension designed for quick, offline web and local image editing using the HTML5 Canvas API. 

Right-click any image on the web or click the extension icon to open a dedicated canvas editor window where you can crop, rotate, resize, highlight, draw shapes, and add dynamic text without your data ever leaving your browser.

---

## Features

- **Instant Web Integration**: Right-click any web image via the context menu (`"Edit Image in Shafiart"`) or drag and drop local files directly onto the workspace.
- **Visual Cropping**: Precise rectangular cropping with visual boundary highlights.
- **Aspect Ratio Resizing**: Scale images proportionally with locked aspect ratios or enter custom width/height pixel dimensions.
- **Rotation & Angle Adjustments**: Rotate by 90° increments or fine-tune custom rotation angles.
- **Marker Highlighter**: Soft-blend semi-transparent highlighter strokes with 8 customizable color swatches.
- **Dynamic Text & Shapes**: Add customizable text overlays, straight lines, rectangles, rounded rectangles, and circles with adjustable fill and border properties.
- **Clipboard Integration**: Instantly copy your edited canvas image to your system clipboard to paste directly into other software (Figma, Photoshop, Slack, etc.).
- **100% Offline & Private**: Operates entirely client-side. No remote code execution, tracking, or data uploading.

---

## Installation for Developers (Local Unpacked)

If you want to run or test Shafiart locally:

1. Clone or download this repository to your local machine.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** using the toggle switch in the top-right corner.
4. Click the **Load unpacked** button in the top-left corner.
5. Select the folder containing your Shafiart project files (`manifest.json`, `editor.html`, etc.).
